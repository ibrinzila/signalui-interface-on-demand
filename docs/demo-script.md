# Three-minute demonstration script

## Recording setup

- Build and start the app.
- Use a 1440×900 or 1440×1000 browser window.
- Start from a reset manager workspace.
- Keep browser zoom at 100%.
- Do not open developer tools during the primary story.

## 0:00–0:20 — The old assumption

Show the full portfolio dashboard.

Say:

> Software used to make humans learn its interface. SignalUI asks the opposite question: what if the interface learned what this human needs right now?

Point out that the workspace contains seven cases, evidence, history, queue state and audit controls.

## 0:20–0:45 — Ask for the interface needed now

Enter:

> I’m on my phone and leaving shortly. Help me resolve only the anomalies that genuinely need my decision.

Select **Field operator** or press **Adapt interface**.

The page recompiles to three decision cards.

Say:

> This is not generated HTML. The model can express intent, but SignalUI compiles only validated surface recipes from capabilities, state and policy.

## 0:45–1:15 — Prove nothing material disappeared

Show:

- three decisions;
- meter photo and history;
- the Community Library counterevidence;
- “Nothing material was removed”;
- “Why am I seeing this?” and “Show full workspace”.

Open the explanation panel briefly.

Say:

> The interface may remove irrelevant navigation. It may not remove evidence that could change the decision, authority gates, exact previews or reversal controls.

## 1:15–1:55 — Human and agent share one governed command path

For School No. 14:

1. Propose `4,829 kWh`.
2. Use the supplied evidence-grounded reason.
3. Request manager approval.

Open the WebMCP/fallback console and show that the available tools changed with state.

Attempt approval as the operator. It is denied and receipted.

Say:

> Presentation never grants authority. Human clicks and WebMCP tools enter the same command bus. Even a known tool that is probed out of context is re-admitted at execution time.

## 1:55–2:25 — Exact human approval

Switch explicitly to **Portfolio manager**.

Open the approval preview and show:

- original value;
- proposed value;
- reason;
- evidence IDs/digest;
- current version;
- approval fingerprint.

Approve.

Say:

> The manager approves this exact state—not a conversational promise. If the evidence or version changes, the approval becomes stale.

## 2:25–2:50 — The same application becomes the auditor’s interface

Select **Auditor**.

Show the read-only audit surface, counts and receipt timeline. Point to human and agent sources, prior/current state hashes and the denied operator action.

Say:

> Same application. Same state. Same capabilities. A radically different interface because the human’s purpose is different.

## 2:50–3:00 — Closing line

Return to the headline or focused surface.

Say:

> SignalUI Interface on Demand: one governed capability model, effectively infinite appropriate interfaces.
